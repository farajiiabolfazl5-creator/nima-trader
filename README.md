# 🚀 Nima Trader

**نیما تریدر** - پلتفرم تجاری حرفه‌ای برای ارزهای دیجیتال و سهام جهانی

## 🌟 ویژگی‌های اصلی

✅ ربات تلگرام حرفه‌ای
✅ دسترسی به بازارهای جهانی
✅ معاملات خودکار و هوشمند
✅ نمودارهای دقیق قیمتی
✅ درگاه‌های متعدد صرافی
✅ پشتیبانی چندزبانه (فارسی، انگلیسی، عربی، چینی)
✅ داشبورد حرفه‌ای آبی-سفید
✅ اتصال API Key و Secret
✅ برداشت و واریز ارز دیجیتال
✅ مدیریت دارایی و پورتفولیو
✅ معادلات بازار در کسری از ثانیه
✅ سرور دائمی و پایدار

## 🛠️ فناوری‌های استفاده شده

- **Backend**: Python (Flask/FastAPI)
- **Frontend**: HTML5, CSS3, JavaScript
- **Database**: PostgreSQL
- **Bot**: python-telegram-bot
- **APIs**: CoinGecko, Binance, IQOption, و دیگر صرافی‌ها
- **Deployment**: Docker, Server Linux

## 📦 نصب و اجرا

```bash
# Clone the repository
git clone https://github.com/farajiiabolfazl5-creator/nima-trader.git
cd nima-trader

# Install dependencies
pip install -r requirements.txt

# Set environment variables
cp .env.example .env
# Edit .env with your API keys

# Run the application
python backend/app.py
```
